Scripting
==========
Scripting means set of commands we are keeping in a file for exection.
We can automate daily task using scripting
For example , i want to execute below commands on daily basic .

-> whoami
-> pwd
-> date
-> cal
-> ls -l

Note: insted of executing one by one manually we can keep them inside a
file and we can execute that file which is called as scripting.

executing this script file using shell is called as shell scripting .

take backup
datele the temp files 
analyze the log files
system health check 


what is the exection we are using for shell scriptng file ?
--> filname.sh

Let's dissucess about shell scripting file 
===========================================
1. shell scripting file will start with sha-bang.

what is sha-bang in shell scripting file ?
==========================================

syntax ---->  #! /bin/bash

sha-bang is not madetory but recommended .

scripting01.sh
===================
#! /bin/bash
echo "hello world!"

testuser@ubuntu:~$ sh script01.sh
hello world!

script03.sh
===========
Enter the input from console 

#! /bin/bash
echo "ENTER YOUR NAME"
read NAME

output
======
testuser@ubuntu:~$ sh script03.sh
ENTER YOUR NAME
sumit
testuser@ubuntu:~$


script04.sh
===========
Enter the input from console and display that name also on the console.

#! /bin/bash
echo "ENTER YOUR NAME"
read NAME
echo "Myname is $NAME"

output
========
testuser@ubuntu:~$ testuser@ubuntu:~$ sh script04.sh
ENTER YOUR NAME
sumit
Myname is sumit
testuser@ubuntu:~$


script05.sh
===========
Enter the input for your first name and last name from console 
and display that name also on the console.

#! /bin/bash
echo "enter first name"
read fname
echo "enter last name"
read lname
echo "My first name is $fname and lastname is $lname"

output
========
testuser@ubuntu:~$ vi script05.sh
testuser@ubuntu:~$ sh script05.sh
enter first name
sumit
enter last name
upadhyay
My first name is sumit and lastname is upadhyay
testuser@ubuntu:~$
